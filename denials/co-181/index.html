CO-181: Procedure code invalid on the date of service

CO-181 means: Procedure code was invalid on the date of service. The code existed at some point but was not valid on the day the service happened.

Read the group code before you act on this

181 is the claim adjustment reason code. The CO in front of it is the group code — a separate field the payer sets on the remittance. The same reason code arrives under different group codes depending on the payer and the situation, and the group code, not the reason code, decides who owes the money.

  • CO — contractual obligation. You write it off. You may not bill the patient.
  • PR — patient responsibility. Billable to the patient.
  • OA — other adjustment, and PI — payer initiated reduction. Neither is patient responsibility.

What causes it

  • Annual code set update — the code was deleted or replaced effective 1 January
  • A new code billed for a date before its effective date
  • A code from a superseded local list still in a favourites list or a charge master
  • Back-dated claim billed with the current year’s code

How to work it

  1. Look the code up against the code set in force on the date of service, not today’s.
  2. Find the replacement code and its effective date, then resubmit corrected.
  3. Check whether the same stale code sits in the charge master or a favourites list — if it does, every claim using it is denying.
  4. Where the claim is old, check the timely filing window before spending effort on it.

How to stop it recurring

Update the charge master and clinical favourites lists with the annual code set, and audit for deleted codes in the first week of January rather than discovering them through denials in March.
